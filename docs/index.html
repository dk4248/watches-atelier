Every part, really working

Explode any watch to see how it's built. Each of its 56 to 75 parts has a label, a description and live readouts.

  • Real gear trainsTooth counts and ratios from each calibre. Every pair of wheels meshes and turns at its true speed.
  • Solved escapementsThe pallet stones lock and impulse the escape wheel tooth by tooth, at 21,600 or 28,800 beats an hour.
  • Spring Drive glideThe Grand Seiko's glide wheel turns continuously at 8 Hz, so its seconds hand sweeps without a tick.
  • WindingTurn the watch and the rotors swing under gravity and wind the mainspring; the crown winds every watch.
  • Four viewsDial, movement, X-ray and exploded, plus a cinematic loop that tours the parts.
  • Themed backgroundsThe wallpaper's colours follow the watch you're wearing, in light or dark.

Install

The whole replica is one offline HTML file. It needs no server and no internet connection once it's on your computer.

Windows

with Lively Wallpaper (free)

  1. Install Lively Wallpaper from the Microsoft Store, or run: 
    winget install --id rocksdanister.LivelyWallpaper -e
  2. Download watches-atelier-lively.zip.
  3. Open Lively, click + (Add wallpaper) and drop the zip in, or browse to it.
  4. Click the new Watch Atelier tile to set it as your wallpaper. Lively doesn't apply imported zips automatically.
  5. Optional: right-click the tile and choose Customise to set the watch of the day, view, idle time, labels, power saving and background.
Download for Lively (.zip)
Tips

Clicks reach the watch only on empty desktop. To keep icons out of the way, right-click the desktop and turn off View → Show desktop icons.

Lively pauses the wallpaper behind full-screen and maximised apps, so it costs nothing while you work.

Wallpaper missing after a restart?

Lively sometimes starts before your monitor has woken up, and then skips the wallpaper and never retries. The guard fixes this. It's a small scheduled task that runs as you, with no admin rights and no window. After sign-in, on unlock and every 5 minutes, it puts Watch Atelier back if Lively's saved layout wants it but nothing is playing. A wallpaper you pick yourself is left alone.

Download watches-atelier-guard.zip, unzip it, and run this in that folder. Add -Remove to take it out again:

powershell -NoProfile -ExecutionPolicy Bypass -File install-guard.ps1

The install script below sets the guard up automatically.

Updating, or installing from the repository

To update, delete the old tile in Lively and import the new zip.

From a clone of the repository, this script installs or updates in place and keeps your settings:

powershell -NoProfile -ExecutionPolicy Bypass -File tools\install-lively.ps1

Linux

with a web-page wallpaper host

  1. Download watches-atelier.html and keep it somewhere permanent, for example your home folder. Or clone the repository; the same file is at docs/wallpaper/index.html.
  2. Set it as your wallpaper, using the steps for your desktop below.
Download the wallpaper (.html)

KDE Plasma (recommended)

  1. Right-click the desktop and open Desktop and Wallpaper….
  2. Next to Wallpaper type, click Get New Plugins…, search for HTML Wallpaper and install it.
  3. Choose HTML Wallpaper as the wallpaper type and set its URL to 
    file:///home/<you>/watches-atelier.html
  4. To click and drag the watch, change Layout at the top of the same dialog from Folder View to Desktop. In Folder View the icons take the clicks.

If the wallpaper stays blank, install Qt WebEngine: sudo pacman -S qt6-webengine (Arch), sudo dnf install qt6-qtwebengine (Fedora) or sudo apt install qml6-module-qtwebengine (Debian, Ubuntu).

Hyprland

The hyprwinwrap plugin from hyprland-plugins pins a window as the wallpaper. Open the file in a Chromium-based browser in app mode and add the window rule from hyprwinwrap's README:

chromium --app=file:///home/<you>/watches-atelier.html

GNOME

GNOME can't use a web page as its wallpaper; its live-wallpaper extensions play videos only. You can still run the replica full screen on a workspace of its own:

chromium --kiosk file:///home/<you>/watches-atelier.html
Use it online instead

Any host that accepts a web address can load the hosted copy. It needs an internet connection when the wallpaper starts:

https://dk4248.github.io/watches-atelier/wallpaper/

Controls & options

  • Click the wallpaper to stop the animation and bring the controls back. Drag to turn the watch.
  • + / − zoom. The mouse wheel works where your wallpaper host passes it through.
  • Watch box (or B) opens the leather box. Click a watch to wear it today; your choice is remembered.
  • Wind turns the crown. On the automatics, turning the watch swings the rotor too.
  • After 2 minutes without input it returns to the wallpaper loop.

Add options to the address after #wallpaper, separated by dots. For example: watches-atelier.html#wallpaper.dial.taskbar0

OptionEffect
dial movement explodedA fixed view instead of the cinematic loop
w-gs-sbga211Start with a given watch: w-tangente-139, w-gs-sbga211, w-tangente-update-147 or w-tudor-m79470
idle300 idleneverSeconds without input before returning to the wallpaper
nolabelsHide part labels in the wallpaper
fps30 fps60Always 30 fps to save power, or never drop to 30 fps when idle
